# SeethaKalyanam
சீதா கல்யாணம் என்பது இராமாயணம் என்னும் இதிகாசத்தில் வரும் மிக முக்கியமான நிகழ்வாகும். இது இராமர் மற்றும் சீதா அவர்களின் திருமணத்தை குறிக்கிறது.

மிதிலா நாட்டின் மன்னன் ஜனகர் தனது மகள் சீதாவிற்கு சிறந்த வரனை தேர்வு செய்ய ‘ஸ்வயம்வரம்’ நடத்துகிறார். அந்த ஸ்வயம்வரத்தில், சிவதனுஸ் என்ற சிவபெருமானின் வில்லைக் கூடியவர் மட்டுமே சீதாவை மணக்கலாம் என்ற நிபந்தனை வைக்கப்படுகிறது. பல அரசர்களும் போர்வீரர்களும் அந்த வில்லைக் கையாள முடியாமல் தோல்வியடைந்தனர்.

அப்போது, விஷ்வாமித்திர முனிவருடன் வந்த இராமர் அந்த வில்லைக் எளிதில் தூக்கி முறித்தார். இதனால் அவர் சீதாவை மணக்க தகுதியானவர் என நிரூபிக்கப்பட்டார். பின்னர், இராமர் மற்றும் சீதாவின் திருமணம் மகிழ்ச்சியுடன் நடைபெறுகிறது.

சீதா கல்யாணம் என்பது தர்மம், அன்பு, மற்றும் வாழ்க்கைத் துணைத் தேர்வின் முக்கியத்துவத்தை எடுத்துக்காட்டுகிறது. இது இந்து மரபில் ஒரு புனித நிகழ்வாகவும், பல இடங்களில் விழாவாகவும் கொண்டாடப்படுகிறது.
